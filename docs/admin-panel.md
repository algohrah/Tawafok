## الدخول والحدود الأمنية
/admin يعرض AdminLayout، الذي يحاول /api/whoami و/api/admin-auth ثم مسار مصادقة محلي عند عدم توفرهما. server.ts لا يعرّف هذين endpoint بل /api/health فقط وخادم Vite. وجود محاولة API ليس خدمة مصادقة منشورة. تحقق محلي عبر adminAuth، وجلسات وعلامات localStorage. authClient يسمح للبريد الإداري بتجاوز بحث الأعضاء؛ لا تعتبر هذه الطبقة وحدها تحقق كلمة مرور. لا ندرج كلمات مرور أو قيم hashes. راجع K-05 وK-07 في الملف الرئيسي قبل تغيير المصادقة أو النشر.

AppContext يعرّف super_admin وحسابات مشرفين وصلاحيات manage_members/manage_requests/manage_support/manage_content/view_sensitive_data. لا يوجد تدقيق إثبات تطبيق هذه الصلاحيات على كل إجراء أو حماية خادمية؛ لا تعِد بأن إخفاء الواجهة ضمان أمن.

## مراكز اللوحة
`/admin` و`/admin/overview` يحمّلان AdminOverviewHub، والذي يجمع Dashboard/Analytics؛ لا تعتبر AdminDashboard وحده عنصر route المباشر.
المسارات الرئيسية: /admin و/admin/overview، /admin/members (ومرادفه members-hub)، /admin/journeys، /admin/finance، /admin/trust، /admin/settings. اختيار الأقسام عبر ?tab=. المكونات Hub تجمع الصفحات ولا تعني صفحات مستقلة جديدة.

## ADM-07 — AdminRequests

**الوجهة:** `/admin/journeys`؛ **المصدر:** `AdminRequests.tsx` → `AdminJourneyConsole.tsx`.

وحدة مشتركة لجميع الطلبات والمسجلين والمستوردين، مع البحث والمرشح حسب المصدر والمرحلة والتعليق. تعرض الطرفين وفتح/تعديل ملفهما، مصدر القرار، وسبب إلزامي لكل إجراء يُسجل قبل/بعد مع المسؤول والوقت. لا ترحيل للرحلات القديمة بعد البداية النظيفة.

- تعديل كل المراحل الخمس أو الاعتذار/الإلغاء، رجوع أو استئناف وإعادة تنشيط/تجميد يدوياً؛ لا تقدم تلقائي من مرور الوقت أو دفع.
- **دفعات مستقلة للطرفين:** مبلغ فعلي، مرجع فريد، تاريخ، مسؤول وسبب. ٣٠٠ من ٢٥٠٠ = ٢٢٠٠ متبقٍ. تصحيح مبلغ يُضاف كسجل تصحيح مع حفظ الأصل؛ منع السالب/الزيادة غير المقصودة/المرجع المكرر/الفقد عند فشل الحفظ.
- موافقة كل طرف، جهة مستلمة للتواصل، تاريخ ومؤشر مشاركة؛ منع مشاركة جديدة دون موافقتين والجهة/التاريخ. لا إرسال خارجي آلي ولا استنتاج موافقة من السداد.
- الخطبة وتسليم المهر وتاريخه والنتيجة مستقلة عن المرحلة والدفعات. اكتمال المرحلة أو الرسوم لا يثبت زواجاً.
- مسؤول متابعة، إجراء قادم وموعد، ملاحظات داخلية، وتعديل إجمالي/هدف أولي للطلب نفسه مع سبب؛ إعداد عام جديد لا يعيد تسعير الطلبات القائمة تلقائياً.
- توجيهات إدارية تظهر للعضو دون الملاحظات الداخلية وسجل التدقيق/مراجع التحويل. كل زر يحفظ قسمه فقط؛ رسائل الفشل ظاهرة. لا محادثة أعضاء.

**حدود جوهرية:** يظهر تحذير التخزين المحلي. صلاحيات الإدارة محلية، لا backend آمن أو بيانات مشتركة. لا مدفوعات حقيقية نُفّذت في التحقق.

## مكونات مساعدة
AdminMemberDetailModal: تفاصيل وتعديل بيانات العضو؛ CustomListsPanel: قوائم مخصصة؛ AdminQuickSearch: بحث سريع؛ ActionMenu/FilterDropdown/MultiSelectFilter: أدوات إجراءات وفلاتر؛ GeoSuggestionsPanel: اقتراحات جغرافية. لا تعد مسارات مستقلة.

## وظائف ثابتة مقابل إعدادات
AdminPlans يعلن نموذجاً تجريبياً ثابتاً؛ لا تصفه محرر باقات كامل. AdminSecuritySettings يعرض مفاتيح 2FA وSMS وبريد ونسخ دوري، ولا يثبت وجود خدمات تعمل بهذه المفاتيح. حسابات الإدارة وصلاحياتها موجودة في AppContext، وليس مجرد ظهور صفحة الأمان دليلاً على إدارة حسابات داخلها.

## جرد الملفات غير المستقلة
ستة ملفات Hub موثقة كتجميع تبويبات؛ AdminLogin باقٍ غير مستخدم كمسار مستقل؛ GeoSuggestionsPanel داخل مجال الجغرافيا. بذلك يشمل الجرد ملفات صفحات المصدر الـ49 بين صفحات مستقلة ومكونات تجميع/مساعدة، دون الادعاء بوجود 49 صفحة مستقلة.
